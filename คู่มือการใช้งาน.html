บทที่ 1 : บทนำและภาพรวมของระบบ

ระบบ X-RayCare QC Management System เป็นเว็บแอปพลิเคชันซึ่งพัฒนาขึ้นเพื่อใช้สำหรับงานควบคุมคุณภาพ (Quality Control) เครื่องเอกซเรย์และอุปกรณ์ทางรังสีวิทยาภายในโรงพยาบาล โดยรวบรวมการลงทะเบียนเครื่องมือ การตรวจสอบรายวัน รายเดือน การจัดตารางบำรุงรักษา การแจ้งซ่อม และการวิเคราะห์ความเสี่ยงไว้ในแพลตฟอร์มเดียวกัน

1.1 เกี่ยวกับระบบ X-RayCare

ระบบนี้พัฒนาขึ้นเพื่อให้สอดคล้องกับมาตรฐานงานประกันคุณภาพในห้องเอกซเรย์ ทดแทนการบันทึกในรูปแบบกระดาษ และสนับสนุนการทำงานร่วมกันระหว่างผู้ปฏิบัติงาน 3 บทบาทหลัก ได้แก่ นักรังสีเทคนิค ผู้ดูแลระบบ และวิศวกร โดยข้อมูลทั้งหมดจะถูกจัดเก็บแยกตามโรงพยาบาลที่ผู้ใช้งานสังกัด

1.2 วัตถุประสงค์ของระบบ

  • เพื่อรวบรวมและบันทึกข้อมูลการตรวจสอบคุณภาพเครื่องเอกซเรย์ในรูปแบบดิจิทัล
  • เพื่อแจ้งเตือนผู้ปฏิบัติงานให้ดำเนินการตรวจสอบตามรอบเวลาที่กำหนดอย่างครบถ้วน
  • เพื่อสนับสนุนกระบวนการแจ้งซ่อมและติดตามสถานะระหว่างหน่วยงานรังสีกับวิศวกร
  • เพื่อวิเคราะห์ข้อมูลและประเมินความเสี่ยงด้านคุณภาพของเครื่องมือ
  • เพื่อจัดทำรายงานและพิมพ์เอกสารเพื่อใช้ในการตรวจประเมินภายในและภายนอก

1.3 คุณสมบัติเด่นของระบบ

การจัดการเครื่องมือและตารางตรวจสอบ

รองรับการลงทะเบียนเครื่องเอกซเรย์ พร้อมระบุห้องตรวจ ผู้ดูแล และความถี่ในการตรวจสอบ พร้อมระบบปฏิทินสำหรับวางแผน Preventive Maintenance (PM)

แบบฟอร์ม QC ครอบคลุมทุกความถี่

รวมแบบฟอร์มมาตรฐาน F1 ถึง F13 ทั้งการตรวจรายวัน รายเดือน ราย 3 เดือน และราย 6 เดือน รวมถึงตัวสร้างแบบฟอร์มกำหนดเอง (Custom Form Builder)

ระบบแจ้งเตือนอัตโนมัติ

แสดงรายการเครื่องที่ถึงรอบตรวจสอบในหน้า Dashboard พร้อมระบุจำนวนวันที่เหลือ และเตือนทันทีเมื่อถึงกำหนด

ระบบแจ้งซ่อมและติดตามสถานะ

ผู้ปฏิบัติงานสามารถแจ้งซ่อมไปยังวิศวกรได้โดยตรง พร้อมติดตามสถานะการดำเนินงานจนกว่าจะแล้วเสร็จ

การวิเคราะห์เชิงลึกและรายงาน

มีหน้า Analytical สำหรับแสดงผลในรูปแบบกราฟ สถิติการผ่าน QC อัตราการแจ้งซ่อม และระดับความเสี่ยงรายเครื่อง พร้อมส่งออกเป็นไฟล์ PDF เพื่อใช้พิมพ์

2.3 บัญชีผู้ใช้งาน

  • บทบาท (Role) ที่กำหนดให้ผู้ใช้งาน เช่น Radiological Technologist, Engineer หรือ Admin

บทที่ 4 : การเข้าสู่ระบบ (Login)

4.1 ขั้นตอนการเข้าสู่ระบบ

  1. เปิดเว็บเบราว์เซอร์ที่ติดตั้งบนอุปกรณ์ของท่าน
  2. ระบุที่อยู่ของระบบในช่องที่อยู่ของเบราว์เซอร์ เช่น http://<ip-address>:5173 หรือที่อยู่ที่ผู้ดูแลระบบกำหนด
  3. ระบบจะแสดงหน้า Welcome — Sign in to X-RayCare QC System ซึ่งมีช่องสำหรับกรอกข้อมูล
  4. กรอกชื่อผู้ใช้งานในช่อง Username
  5. กรอกรหัสผ่านในช่อง Password และสามารถกดไอคอนรูปดวงตาเพื่อแสดง/ซ่อนรหัสผ่านได้
  6. เลือก โรงพยาบาล ที่ท่านสังกัดจากรายการดรอปดาวน์
  7. กดปุ่ม Sign In เพื่อเข้าสู่ระบบ
✓
เคล็ดลับ
หลังเข้าสู่ระบบสำเร็จ ระบบจะนำท่านไปยังหน้า Dashboard ที่เหมาะสมกับบทบาทโดยอัตโนมัติ ผู้ดูแลระบบจะถูกนำไปยัง Admin Dashboard, วิศวกรไปที่ Engineer Dashboard และนักรังสีเทคนิคไปที่ Dashboard ปกติ

4.2 กรณีเข้าสู่ระบบไม่สำเร็จ

ข้อความที่แสดงสาเหตุและวิธีแก้ไข
กรุณากรอก Username และ Password ผู้ใช้งานยังไม่ได้กรอกข้อมูลในช่องใดช่องหนึ่ง ให้ตรวจสอบและกรอกข้อมูลให้ครบถ้วน
ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบความถูกต้องของชื่อผู้ใช้ รหัสผ่าน และโรงพยาบาลที่เลือก หากยังคงพบปัญหา ให้ติดต่อผู้ดูแลระบบ
เกิดข้อผิดพลาด กรุณาลองใหม่อีกครั้ง เกิดจากปัญหาการเชื่อมต่อกับเครื่องแม่ข่าย กรุณาตรวจสอบเครือข่ายของท่าน หรือแจ้งผู้ดูแลระบบ

4.3 การออกจากระบบ

เมื่อท่านใช้งานเสร็จแล้ว สามารถออกจากระบบได้โดยเลื่อนลงไปยังด้านล่างของแถบเมนูด้านซ้าย แล้วกดปุ่ม Logout เพื่อความปลอดภัย ระบบแนะนำให้ออกจากระบบทุกครั้งหลังเลิกใช้งาน โดยเฉพาะอย่างยิ่งเมื่อใช้งานบนเครื่องคอมพิวเตอร์สาธารณะ

บทที่ 5 : โครงสร้างหน้าจอและการนำทาง

หลังเข้าสู่ระบบสำเร็จ ผู้ใช้งานจะพบกับหน้าจอหลักซึ่งประกอบด้วยส่วนสำคัญ 3 ส่วน ได้แก่ แถบด้านบน (Top Bar), แถบเมนูด้านข้าง (Sidebar) และพื้นที่แสดงเนื้อหาของแต่ละหน้า

5.1 แถบด้านบน (Top Bar)

แสดงข้อมูลของผู้ใช้งานและโรงพยาบาลที่สังกัด รวมถึงเมนูสำหรับไปยังโปรไฟล์ส่วนบุคคล และในกรณีที่ผู้ใช้เป็น Super Admin จะสามารถสลับโรงพยาบาลที่ดูแลได้จากแถบนี้

5.2 แถบเมนูด้านข้าง (Sidebar Navigation)

เป็นเมนูหลักของระบบ จัดกลุ่มตามบทบาทผู้ใช้งาน เพื่อให้ง่ายต่อการค้นหาเมนูที่ต้องการใช้งาน

  • กลุ่ม Radiological Technologist — สำหรับนักรังสีเทคนิค ประกอบด้วย Dashboard, Equipment, Daily Check, Monthly Check, PM Schedule, QC Forms, Request, Export PDF และ Analytical
  • กลุ่ม Admin — สำหรับผู้ดูแลระบบ ประกอบด้วย Admin Dashboard, User & Hospital Management และ Admin Analytics

  • เมนูทั่วไป — Profile และปุ่ม Logout

บทที่ 6 : คู่มือสำหรับนักรังสีเทคนิค

บทนี้รวบรวมเมนูและฟังก์ชันการใช้งานที่นักรังสีเทคนิคต้องใช้เป็นประจำในการดูแลคุณภาพของเครื่องเอกซเรย์

6.1 Dashboard — หน้าภาพรวม

หน้า Dashboard เป็นหน้าหลักที่แสดงภาพรวมของงานทั้งหมดในวันนั้น ๆ ประกอบด้วย

  • แถบแจ้งเตือน — แสดงรายการเครื่องที่ใกล้ครบกำหนดการตรวจสอบ พร้อมระบุจำนวนวันที่เหลือหรือสถานะ "ถึงกำหนดแล้ว"
  • การ์ดสรุป (Summary Cards) ประกอบด้วย วันที่ปัจจุบัน, จำนวนเครื่องทั้งหมด, จำนวนรายการรอตรวจ และจำนวนคำขอแจ้งซ่อม
  • ตาราง Checklist — รายการเครื่องเอกซเรย์ที่ต้องตรวจในวันนั้น พร้อมข้อมูลห้องและผู้ดูแล
  • ปฏิทินและสถานะเครื่อง — แสดงปฏิทินรายเดือนและสถานะของเครื่องแต่ละเครื่อง

การใช้งาน

  1. หลังเข้าสู่ระบบ ระบบจะนำท่านมายังหน้านี้โดยอัตโนมัติ
  2. ตรวจสอบแถบแจ้งเตือนด้านบนสุด หากมีรายการที่ถึงกำหนด ให้ดำเนินการตรวจตามรายการนั้นก่อน
  3. หากต้องการบันทึกการตรวจสอบเครื่องใด ให้กดปุ่ม Check ในช่อง Action ของแถวที่ต้องการ
  4. หากต้องการเพิ่มเครื่องเอกซเรย์ใหม่ ให้กดปุ่ม + Add Equipment ที่อยู่ด้านบนของตาราง

6.2 Equipment — ลงทะเบียนเครื่องเอกซเรย์

ใช้สำหรับเพิ่มเครื่องเอกซเรย์ใหม่เข้าสู่ระบบ และจัดการเครื่องที่ลงทะเบียนไว้แล้ว

ขั้นตอนการเพิ่มเครื่องใหม่

  1. เข้าเมนู Equipment หรือกดปุ่ม Add Equipment จากหน้า Dashboard
  2. กรอกข้อมูลเครื่องในแบบฟอร์ม ได้แก่ ชื่อเครื่อง ยี่ห้อ รุ่น ห้องที่ติดตั้ง วันที่ติดตั้ง และผู้ดูแล
  3. กดปุ่ม บันทึก เพื่อเพิ่มเครื่องเข้าสู่ระบบ
  4. เครื่องที่เพิ่มจะปรากฏในตารางด้านล่างของหน้านี้และในหน้า Dashboard ทันที

การลบเครื่องที่ลงทะเบียนไว้

ในตารางเครื่องที่ลงทะเบียนแล้ว ให้เลือกแถวที่ต้องการลบโดยติ๊กในช่องแรก จากนั้นกดปุ่ม ลบรายการที่เลือก ระบบจะแสดงกล่องยืนยันก่อนทำการลบ

!
คำเตือน

6.3 Daily Check — การตรวจเช็ครายวัน

หน้านี้ใช้บันทึกผลการตรวจสอบประจำวันสำหรับเครื่องเอกซเรย์แต่ละเครื่อง โดยอ้างอิงตามแบบฟอร์ม F1 และ F2 ของระบบ QC

ขั้นตอนการบันทึก Daily Check

  1. จากหน้า Dashboard ให้กดปุ่ม Check หลังชื่อเครื่องที่ต้องการ
  2. ระบบจะเปิดหน้า Daily Check พร้อมแสดงข้อมูลเครื่อง ห้อง และผู้ทดสอบโดยอัตโนมัติ
  3. กรอกหรือเลือกผลในตาราง การดูแลรักษาและตรวจสอบเครื่องเอกซเรย์ ทีละรายการ
    • เลือก ผ่าน / ไม่ผ่าน
    • กรณีไม่ผ่าน ให้ระบุหมายเหตุ และสามารถแนบรูปภาพประกอบได้
  4. กรอกตาราง การลบแผ่นเพลท ตามรายการที่ปรากฏ
  5. เพื่อความรวดเร็ว สามารถใช้ปุ่ม ผ่านทั้งหมด เพื่อทำเครื่องหมายผ่านทุกข้อพร้อมกัน
  6. เมื่อกรอกครบถ้วนแล้ว เลือกการดำเนินการ
    • กดปุ่ม บันทึก เพื่อบันทึกและกลับสู่หน้า Dashboard
    • หรือกดปุ่ม ถัดไป เพื่อไปยังแบบฟอร์ม Monthly Check (ในกรณีที่ครบรอบเดือน)
✓
ข้อแนะนำ
หากพบรายการที่ไม่ผ่านการตรวจสอบ ระบบจะสร้างคำขอแจ้งซ่อมให้โดยอัตโนมัติเพื่อส่งต่อให้วิศวกรพิจารณา ท่านสามารถระบุรายละเอียดเพิ่มเติมเพื่อให้การซ่อมแซมรวดเร็วยิ่งขึ้น

6.4 Monthly Check — การตรวจราย 3 เดือน (F3–F6)

หน้านี้รวมแบบฟอร์มการตรวจสอบที่ต้องดำเนินการทุก 3 เดือน 4 รายการ ได้แก่

แบบฟอร์มชื่อเต็มวัตถุประสงค์
F3Monitor Quality Testตรวจสอบคุณภาพของจอภาพแสดงผลในห้องเอกซเรย์
F4X-ray Quality Checkตรวจสอบคุณภาพของลำแสง X-ray ที่ออกจากเครื่อง
F5Uniformity Testตรวจสอบความสม่ำเสมอของภาพที่ได้จากเครื่อง
F6Exposure Index Consistencyตรวจสอบความคงที่ของค่า Exposure Index

ขั้นตอนการใช้งาน

  1. เข้าเมนู Monthly Check จากแถบด้านข้าง
  2. เลือกเครื่องเอกซเรย์ที่ต้องการตรวจสอบ
  3. ระบบจะแสดงแท็บ F3, F4, F5 และ F6 ตามลำดับ
  4. กรอกข้อมูลในแต่ละแท็บให้ครบถ้วน หากต้องการดูแท็บถัดไป ให้กดที่ชื่อแท็บด้านบน
  5. เมื่อกรอกครบทุกแท็บแล้ว กดปุ่ม บันทึก เพื่อบันทึกข้อมูลทั้งหมดในครั้งเดียว

6.5 Monthly Check — การตรวจราย 6 เดือน (F7–F8)

เป็นการตรวจสอบที่ต้องดำเนินการทุก 6 เดือน ครอบคลุม 4 หัวข้อ ได้แก่

  • F7-1 / F7-2 — Collimator Alignment Test สำหรับเครื่องประเภท Bucky และ Tabletop
  • F8-1 — CR Dark Noise Test สำหรับระบบ Computed Radiography
  • F8-2 — DR Dark Noise Test สำหรับระบบ Digital Radiography

ขั้นตอนการใช้งาน

  1. เข้าเมนู Monthly Check All จากแถบด้านข้าง
  2. เลือกเครื่องที่ต้องการตรวจ
  3. กรอกข้อมูลตามแท็บ F7-1, F7-2, F8-1, F8-2 ทีละหัวข้อ
  4. เมื่อบันทึกครบทุกแท็บ กดปุ่ม บันทึก เพื่อยืนยันการตรวจสอบ

6.6 F9 — การตรวจคุณภาพเสื้อตะกั่วและอุปกรณ์ป้องกันรังสี

ใช้บันทึกการตรวจสอบเสื้อตะกั่วและอุปกรณ์ป้องกันรังสีของหน่วยงาน

ฟิลด์ข้อมูลหลัก

  • ประเภทการตรวจ: ภายในหน่วยงาน หรือ ภายนอกหน่วยงาน
  • เลขประจำอุปกรณ์
  • ชนิดของอุปกรณ์ (เสื้อตะกั่ว, ผ้าตะกั่ว, แว่นตาตะกั่ว ฯลฯ)
  • สภาพของอุปกรณ์ (ผ่าน/ไม่ผ่าน) พร้อมหมายเหตุ

วิธีการเพิ่ม/ลบอุปกรณ์

ในตารางอุปกรณ์ ผู้ใช้งานสามารถเพิ่มอุปกรณ์ได้โดยกดปุ่ม + เพิ่มอุปกรณ์ และลบอุปกรณ์ที่ไม่ต้องการได้โดยกดปุ่มลบในแถวนั้น ๆ

6.7 F10 — การตรวจวัดความสว่างของไฟ

ใช้สำหรับบันทึกผลการวัดความสว่างของแสงไฟในห้องตรวจ ซึ่งมีผลต่อคุณภาพของภาพถ่าย

ขั้นตอนการบันทึกข้อมูล

  1. เข้าเมนู Monthly Check Light หรือเข้าผ่านการ์ดในหน้า QC Forms
  2. กรอกข้อมูลหน่วยงาน เลขประจำเครื่อง รุ่นและค่า Calibration ของเครื่องวัด
  3. บันทึกค่าความสว่างเฉลี่ย (I_AV) และค่าแสงรบกวน (Background, I_BG) ในแต่ละครั้งของการทดสอบ
  4. ระบบจะคำนวณและแสดงผลให้อัตโนมัติเมื่อกรอกข้อมูลครบ
  5. กดปุ่ม บันทึก เพื่อจัดเก็บข้อมูล

6.8 F11 — บันทึกผลการวัดความหนาผู้ป่วย

ใช้บันทึกค่าความหนาของผู้ป่วยและค่าทางเทคนิคที่ใช้ในการถ่ายภาพแต่ละครั้ง เพื่อใช้เป็นข้อมูลอ้างอิงในการประเมินคุณภาพของภาพ

ข้อมูลที่ต้องกรอก

  • ข้อมูลผู้ป่วย เช่น HN, ห้องตรวจ, ตำแหน่งที่ถ่าย
  • ค่าความหนาที่วัดได้
  • ค่าทางเทคนิคที่เกี่ยวข้อง เช่น kVp, mAs

6.9 F12 — อัตราการถ่ายภาพซ้ำ / ปฏิเสธภาพ

ใช้สำหรับบันทึกข้อมูลภาพถ่ายที่ต้องถ่ายซ้ำหรือถูกปฏิเสธ เพื่อนำไปวิเคราะห์ปัญหาและปรับปรุงคุณภาพการให้บริการ

ขั้นตอนการกรอก

  1. เลือกสาเหตุของการถ่ายซ้ำ/ปฏิเสธจากรายการที่ระบบกำหนด
  2. หากสาเหตุที่ต้องการบันทึกไม่อยู่ในรายการ ให้เลือก "อื่น ๆ" และระบุข้อความเพิ่มเติม
  3. กดปุ่ม บันทึก เพื่อจัดเก็บข้อมูล

6.10 F13 — การตรวจ B-mode QC สำหรับเครื่องอัลตราซาวด์

ใช้สำหรับบันทึกผลการตรวจ Quality Control ของเครื่องอัลตราซาวด์ในโหมด B-mode ซึ่งเป็นการตรวจสอบคุณภาพของภาพคลื่นเสียง

ในแบบฟอร์มประกอบด้วยฟิลด์สำหรับข้อมูลเครื่อง วันที่ตรวจ ผู้ตรวจ และผลการทดสอบในแต่ละหัวข้อ ผู้ใช้งานควรกรอกข้อมูลให้ครบถ้วนเพื่อความถูกต้องในการนำไปใช้รายงาน

6.11 QC Forms Hub และ Custom Form Builder

QC Forms Hub

เป็นหน้ารวมศูนย์ของแบบฟอร์ม QC เพิ่มเติม ผู้ใช้งานสามารถเข้าถึงแบบฟอร์ม F9, F11, F12, F13 ได้ผ่านการ์ดเมนูในหน้านี้ และสามารถจัดการแบบฟอร์มที่สร้างขึ้นเองได้ที่หน้านี้

Custom Form Builder — ตัวสร้างแบบฟอร์มกำหนดเอง

หน้านี้ออกแบบมาเพื่อให้ผู้ใช้งานสามารถสร้างแบบฟอร์มของตนเองได้อย่างอิสระ โดยมี 3 โหมดการทำงาน

  • Visual Mode — ออกแบบแบบฟอร์มด้วย Rich Text Editor ที่ใช้งานง่าย
  • HTML Mode — เขียนโค้ด HTML ได้โดยตรงสำหรับผู้ใช้ที่มีความรู้ทางเทคนิค
  • Preview Mode — ดูตัวอย่างก่อนการบันทึก

ขั้นตอนการสร้างแบบฟอร์ม

  1. กดปุ่ม + สร้างแบบบันทึก ที่หน้า QC Forms Hub
  2. ตั้งชื่อและรายละเอียดของแบบฟอร์ม
  3. ใช้ Visual Mode หรือ HTML Mode เพื่อออกแบบแบบฟอร์ม
  4. กดปุ่ม Preview เพื่อดูตัวอย่าง
  5. กดปุ่ม บันทึก เพื่อจัดเก็บแบบฟอร์มเข้าสู่ระบบ

6.12 PM Schedule — ตารางบำรุงรักษาเชิงป้องกัน

ใช้สำหรับวางแผนและกำหนดตารางการตรวจสอบหรือบำรุงรักษาเครื่องเอกซเรย์ตามรอบเวลา ระบบจะนำตารางนี้ไปใช้สร้างการแจ้งเตือนในหน้า Dashboard อัตโนมัติ

ขั้นตอนการตั้งค่าตาราง

  1. เข้าเมนู PM Schedule จากแถบด้านข้าง
  2. กดเลือกวันที่ที่ต้องการในปฏิทินที่ปรากฏ
  3. ระบบจะเปิดหน้าต่างให้กรอกข้อมูล กำหนดประเภทแบบฟอร์ม (เช่น F1_F2, F10) และความถี่ในการตรวจ (รายวัน, รายเดือน, ทุก 3 เดือน, ทุก 6 เดือน)
  4. กดปุ่ม บันทึก เพื่อสร้างกำหนดการ
  5. หากต้องการแก้ไขหรือลบ สามารถกดที่กำหนดการในปฏิทินเพื่อดำเนินการได้

6.13 Request — การแจ้งซ่อม

ใช้สำหรับแจ้งปัญหาของเครื่องเอกซเรย์ไปยังวิศวกร ผู้ใช้งานสามารถแนบรายละเอียดและรูปภาพประกอบได้

ขั้นตอนการแจ้งซ่อม

  1. เข้าเมนู Request จากแถบด้านข้าง
  2. กดปุ่ม + เพิ่มรายการ ที่ด้านบนของตาราง
  3. กรอกข้อมูลในกล่องโต้ตอบ ได้แก่ เครื่องที่มีปัญหา รายละเอียดอาการ ระดับความเร่งด่วน
  4. กดปุ่ม บันทึก เพื่อส่งคำขอ

การติดตามสถานะ

คำขอที่บันทึกแล้วจะปรากฏในตารางพร้อมแสดงสถานะปัจจุบัน เช่น รอดำเนินการ, กำลังดำเนินการ, เสร็จสิ้น ผู้ใช้งานสามารถกดที่แถวเพื่อดูรายละเอียดเพิ่มเติม หรือกดลบเพื่อยกเลิกคำขอได้

6.14 Export PDF — การส่งออกรายงาน

ใช้สำหรับเรียกดูประวัติการบันทึก Checklist และส่งออกเป็นไฟล์ PDF เพื่อใช้พิมพ์หรือจัดเก็บเป็นหลักฐาน

ฟังก์ชันที่มีในหน้านี้

  • ตารางรายการบันทึก Checklist พร้อมตัวกรอง (เครื่อง, ประเภทแบบฟอร์ม, ช่วงวันที่)
  • ปุ่มดูพรีวิว/พิมพ์รายการแต่ละแถว
  • ส่วน Export PDF รายเดือน (F1/F2) สำหรับสรุปการตรวจรายวันออกเป็นไฟล์ PDF รายเดือน

ขั้นตอนการส่งออก

  1. เลือกตัวกรองตามต้องการ เช่น เลือกเครื่อง เลือกแบบฟอร์ม และระบุช่วงวันที่
  2. หากต้องการส่งออกรายการเดี่ยว ให้กดปุ่ม พิมพ์ ที่แถวนั้น
  3. หากต้องการส่งออกแบบรายเดือน ให้กดปุ่ม ส่งออก PDF รายเดือน
  4. ระบบจะเปิดหน้าพรีวิวสำหรับพิมพ์ ให้กดปุ่ม Ctrl + P เพื่อบันทึกเป็น PDF

6.15 Analytical — ศูนย์วิเคราะห์ความเสี่ยง

หน้านี้รวบรวมข้อมูลเชิงสถิติและวิเคราะห์ระดับความเสี่ยงของเครื่องเอกซเรย์ในแผนก

ส่วนประกอบของหน้า

  • KPI Cards — จำนวนเครื่อง, อัตราการผ่าน QC, จำนวนคำขอแจ้งซ่อมที่ค้างอยู่ และระดับความเสี่ยงโดยรวม
  • กราฟแนวโน้มรายเดือน — แสดงแนวโน้มอัตราการผ่าน QC และความถี่การแจ้งซ่อม
  • กราฟ Donut — แสดงสัดส่วนของผลตามประเภทแบบฟอร์ม
  • กราฟ Bar — แสดงสถิติของแต่ละเครื่องและหัวข้อที่มีปัญหามากที่สุด
  • การประเมินรายเครื่อง — ตารางจัดอันดับความเสี่ยงของเครื่องแต่ละเครื่อง
✓
การใช้งานที่แนะนำ
ควรเข้ามาดูหน้านี้อย่างน้อยสัปดาห์ละ 1 ครั้งเพื่อประเมินสถานการณ์โดยรวมของแผนก ข้อมูลในหน้านี้สามารถใช้เป็นหลักฐานในการประชุมประจำเดือนหรือการตรวจประเมินจากภายนอกได้

บทที่ 7 : คู่มือสำหรับผู้ดูแลระบบ (Admin)

ผู้ดูแลระบบมีหน้าที่จัดการข้อมูลผู้ใช้งานในโรงพยาบาล ตรวจสอบภาพรวมการทำงาน และวิเคราะห์ผลการดำเนินงาน นอกเหนือจากนี้ผู้ดูแลระบบยังสามารถเข้าถึงเมนูทั้งหมดของนักรังสีเทคนิคได้เช่นกัน

7.1 Admin Dashboard — หน้าหลักของผู้ดูแลระบบ

หน้าจอนี้มีลักษณะคล้ายกับ Dashboard ของนักรังสีเทคนิค แต่ออกแบบมาสำหรับผู้ดูแลระบบโดยเฉพาะ ประกอบด้วย

  • แถบแจ้งเตือนรอบการตรวจสอบที่ใกล้ครบกำหนด
  • การ์ดสรุปจำนวนเครื่อง รายการรอตรวจ คำขอแจ้งซ่อม และสถานะอื่น ๆ
  • ตาราง Checklist ของเครื่องในวันนั้น
  • ปฏิทินและสถานะของเครื่องแต่ละเครื่อง

7.2 จัดการผู้ใช้และโรงพยาบาล (User & Hospital Management)

หน้านี้แบ่งออกเป็น 2 แท็บหลัก ได้แก่

7.2.1 แท็บ User — จัดการผู้ใช้งาน

  • ดูรายชื่อผู้ใช้งานทั้งหมดในโรงพยาบาลของท่าน
  • ค้นหาผู้ใช้ด้วยชื่อหรือชื่อผู้ใช้งาน
  • เพิ่มผู้ใช้ใหม่โดยกรอกข้อมูล Username, Password, บทบาท และโรงพยาบาล
  • แก้ไขข้อมูลของผู้ใช้ที่มีอยู่
  • ลบผู้ใช้งานที่ไม่ต้องการ
  • แสดงและซ่อนรหัสผ่านได้ทีละบัญชี

7.2.2 แท็บ Hospital — จัดการข้อมูลโรงพยาบาล

  • เพิ่มโรงพยาบาลใหม่เข้าสู่ระบบ (เฉพาะ Super Admin)
  • แก้ไขข้อมูลของโรงพยาบาลที่มีอยู่
  • ลบโรงพยาบาลที่ไม่ใช้งานออก

ขั้นตอนการเพิ่มผู้ใช้ใหม่

  1. เข้าเมนู User & Hospital Management
  2. เลือกแท็บ User
  3. กดปุ่ม + เพิ่มผู้ใช้
  4. กรอกข้อมูลของผู้ใช้ ได้แก่ ชื่อผู้ใช้ รหัสผ่าน บทบาท (Admin / Radiological Technologist / Engineer) และโรงพยาบาลที่สังกัด
  5. กดปุ่ม บันทึก เพื่อสร้างบัญชี
!
ข้อควรระวัง
เมื่อเปลี่ยนรหัสผ่านหรือบทบาทของผู้ใช้แล้ว การเปลี่ยนแปลงจะมีผลในครั้งถัดไปที่ผู้ใช้รายนั้นเข้าสู่ระบบ กรุณาแจ้งให้ผู้ใช้ทราบล่วงหน้าเพื่อความสะดวกในการปฏิบัติงาน

7.3 Admin Analytics — ศูนย์วิเคราะห์สำหรับผู้ดูแลระบบ

เป็นหน้าวิเคราะห์ความเสี่ยงในรูปแบบเดียวกับ Analytical ของนักรังสีเทคนิค แต่เปิดให้ผู้ดูแลระบบใช้งานจากกลุ่มเมนู Admin โดยเฉพาะ ผู้ดูแลระบบสามารถใช้ข้อมูลในหน้านี้เพื่อ

  • ประเมินภาพรวมประสิทธิภาพการตรวจสอบเครื่องของแผนก
  • ตรวจสอบจำนวนเครื่องที่มีความเสี่ยงสูงและจำเป็นต้องดำเนินการเร่งด่วน
  • นำเสนอผลการดำเนินงานในที่ประชุมหรือใช้ในการตรวจประเมินภายนอก

บทที่ 8 : คู่มือสำหรับวิศวกร (Engineer)

วิศวกรเป็นผู้รับผิดชอบในการดำเนินการคำขอแจ้งซ่อมจากนักรังสีเทคนิค และอัปเดตสถานะการดำเนินงานในระบบ เพื่อให้ผู้ที่เกี่ยวข้องสามารถติดตามความคืบหน้าได้

8.1 Engineer Dashboard — หน้าหลักของวิศวกร

หน้าจอแรกที่วิศวกรจะพบหลังเข้าสู่ระบบ ประกอบด้วย

  • การ์ดสรุปวันที่ จำนวนเครื่องในระบบ จำนวนคำขอแจ้งซ่อมที่ค้างอยู่ คำขอที่กำลังดำเนินการ และคำขอที่เสร็จสิ้นแล้ว
  • ตารางรายการคำขอแจ้งซ่อม แสดงข้อมูลเครื่อง ห้อง ผู้แจ้ง และสถานะ

8.2 Engineer Request — การจัดการคำขอแจ้งซ่อม

เป็นหน้าที่หลักของวิศวกรในการรับและดำเนินการคำขอแจ้งซ่อม

ขั้นตอนการดำเนินการ

  1. เข้าเมนู Engineer Request จากแถบด้านข้าง
  2. ดูรายการคำขอที่ปรากฏในตาราง โดยพิจารณาจากสถานะและระดับความเร่งด่วน
  3. กดที่แถวของคำขอเพื่อดูรายละเอียดของปัญหาและรูปภาพประกอบ (ถ้ามี)
  4. เมื่อเริ่มดำเนินการ ให้เปลี่ยนสถานะเป็น กำลังดำเนินการ
  5. เมื่อแก้ไขเรียบร้อยแล้ว ให้เปลี่ยนสถานะเป็น เสร็จสิ้น เพื่อแจ้งให้ผู้ที่เกี่ยวข้องทราบ
  6. กรณีที่ต้องการลบคำขอ (เช่น เป็นคำขอซ้ำ) สามารถกดปุ่ม ลบ ที่แถวนั้น
i
หมายเหตุ
สถานะของคำขอที่ถูกอัปเดตในหน้านี้จะแสดงผลในหน้า Dashboard และตาราง Request ของนักรังสีเทคนิคและผู้ดูแลระบบโดยอัตโนมัติ

8.3 Engineer Analytics — ศูนย์วิเคราะห์สำหรับวิศวกร

หน้านี้แสดงข้อมูลเชิงวิเคราะห์ที่เป็นประโยชน์ต่อวิศวกร เช่น

  • จำนวนคำขอแจ้งซ่อมที่ได้รับในแต่ละเดือน
  • เครื่องที่ถูกแจ้งซ่อมบ่อยที่สุด
  • ระยะเวลาเฉลี่ยในการดำเนินการแก้ไข
  • ประเภทของปัญหาที่พบบ่อยที่สุด

ข้อมูลเหล่านี้ช่วยให้วิศวกรสามารถวางแผนการบำรุงรักษาเชิงป้องกันและปรับปรุงประสิทธิภาพการทำงานในระยะยาวได้

บทที่ 9 : โปรไฟล์และฟอร์มสำหรับพิมพ์

ขั้นตอนการแก้ไขข้อมูลส่วนตัว

  1. กดเมนู Profile ที่แถบด้านข้าง
  2. แก้ไขข้อมูลในช่องที่ต้องการ
  3. กดปุ่ม บันทึกการเปลี่ยนแปลง

บทที่ 10 : คำถามที่พบบ่อย (FAQ)

1. หากลืมรหัสผ่านต้องทำอย่างไร?

ติดต่อผู้ดูแลระบบของโรงพยาบาลเพื่อรีเซ็ตรหัสผ่านให้ใหม่ ในขณะนี้ระบบยังไม่รองรับการรีเซ็ตรหัสผ่านด้วยตนเอง

2. เหตุใดจึงไม่เห็นเครื่องเอกซเรย์ที่ต้องการในรายการ?

เนื่องจากระบบจัดเก็บข้อมูลแยกตามโรงพยาบาล กรุณาตรวจสอบว่าท่านเลือกโรงพยาบาลที่ถูกต้องในขั้นตอนเข้าสู่ระบบ และเครื่องนั้นได้ถูกลงทะเบียนแล้วหรือไม่ในเมนู Equipment

3. การแจ้งเตือน "ถึงกำหนดแล้ว" ที่หน้า Dashboard เกิดจากอะไร?

ระบบจะคำนวณจากตาราง PM Schedule ที่ผู้ใช้ตั้งไว้ เมื่อถึงวันที่กำหนดของแบบฟอร์มใด ระบบจะแสดงการแจ้งเตือนและขึ้นรายการในตาราง Checklist โดยอัตโนมัติ

4. ข้อมูลที่กรอกค้างไว้แล้วยังไม่ได้บันทึกจะหายไปหรือไม่?

หากปิดเบราว์เซอร์หรือออกจากระบบโดยไม่ได้กดปุ่มบันทึก ข้อมูลที่กรอกค้างไว้จะหายทันที กรุณากดปุ่มบันทึกทุกครั้งหลังกรอกข้อมูลเสร็จ

5. สามารถใช้งานบนโทรศัพท์มือถือได้หรือไม่?

ใช้ได้ ระบบออกแบบให้รองรับ Responsive Design สามารถใช้งานได้ดีทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ อย่างไรก็ตามแนะนำให้ใช้บนหน้าจอขนาดใหญ่กว่า 10 นิ้วเพื่อความสะดวกในการกรอกแบบฟอร์ม

6. หากระบบขัดข้องหรือเชื่อมต่อไม่ได้ต้องทำอย่างไร?

ตรวจสอบการเชื่อมต่อเครือข่ายของท่านเป็นลำดับแรก หากเครือข่ายปกติแต่ระบบยังคงขัดข้อง กรุณาติดต่อผู้ดูแลระบบของหน่วยงาน

7. สามารถส่งออกรายงานเป็นไฟล์รูปแบบอื่นนอกเหนือจาก PDF ได้หรือไม่?

ในปัจจุบันระบบรองรับการส่งออกเป็น PDF ผ่านหน้าพิมพ์เป็นหลัก ผู้ใช้งานสามารถใช้ฟังก์ชัน Save as PDF ของเบราว์เซอร์เพื่อบันทึกเป็นไฟล์ได้

8. หากต้องการเพิ่มแบบฟอร์มใหม่ที่ไม่มีในระบบจะทำได้อย่างไร?

ใช้เมนู Custom Form Builder ในกลุ่ม QC Forms เพื่อสร้างแบบฟอร์มในลักษณะที่ท่านต้องการ
