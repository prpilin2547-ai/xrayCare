ภาพรวมของระบบ

1.1 วัตถุประสงค์

ระบบ X-RayCare QC Management System เป็นระบบเว็บแอปพลิเคชันที่ได้รับการพัฒนาขึ้นเพื่อจัดการงานควบคุมคุณภาพ (Quality Control — QC) ของเครื่องเอกซเรย์และอุปกรณ์ทางรังสีวิทยาภายในโรงพยาบาล โดยมุ่งเน้นการยกระดับมาตรฐานความปลอดภัยและประสิทธิภาพการทำงานของแผนกรังสีวิทยาให้เป็นไปตามข้อกำหนดด้านคุณภาพ

1.2 คุณสมบัติหลักของระบบ

คุณสมบัติรายละเอียด
ลงทะเบียนเครื่องเอกซเรย์บันทึกข้อมูลเครื่อง ห้องตรวจ และผู้ดูแลเครื่องอย่างเป็นระบบ
ตรวจสอบคุณภาพประจำวันบันทึกผลการตรวจสอบเครื่องเอกซเรย์ในแต่ละวัน (Daily Check — F1/F2)
ตรวจสอบคุณภาพประจำเดือนบันทึกผลการตรวจสอบตามรอบ 1, 3 หรือ 6 เดือน (F3–F13)
แบบบันทึก QC เพิ่มเติมแบบฟอร์ม F9 ถึง F13 และการสร้างแบบฟอร์มกำหนดเอง (Custom Form)
ตารางบำรุงรักษาเชิงป้องกันจัดตาราง Preventive Maintenance (PM) พร้อมระบบแจ้งเตือนอัตโนมัติ
ระบบแจ้งซ่อมแจ้งซ่อมอุปกรณ์พร้อมแนบภาพถ่าย ติดตามสถานะการดำเนินงาน
ศูนย์วิเคราะห์ความเสี่ยงแสดงผลวิเคราะห์ KPI อัตราผ่าน QC กราฟแนวโน้ม และระดับความเสี่ยง
ส่งออกรายงาน PDFกรองรายการ Checklist พร้อมพิมพ์เป็นเอกสาร PDF อย่างเป็นทางการ
จัดการผู้ใช้งานและโรงพยาบาลรองรับการบริหารจัดการแบบหลายโรงพยาบาล (Multi-Hospital)

1.4 การรองรับหลายโรงพยาบาล

ระบบรองรับการทำงานแบบหลายโรงพยาบาล (Multi-Hospital) ข้อมูลทั้งหมดจะถูกแบ่งแยกตามโรงพยาบาลที่ผู้ใช้สังกัด ผู้ใช้ที่มีสถานะ Root Admin สามารถสลับดูข้อมูลและบริหารจัดการข้ามโรงพยาบาลได้

ⓘ หมายเหตุ
ผู้ใช้งานทั่วไปจะสามารถเข้าถึงได้เฉพาะข้อมูลของโรงพยาบาลที่ตนสังกัดเท่านั้น ข้อมูลของโรงพยาบาลอื่นจะไม่ปรากฏในระบบ

บทบาทผู้ใช้งานและสิทธิ์การเข้าถึง

ระบบกำหนดบทบาทผู้ใช้งานออกเป็น 5 ระดับ โดยแต่ละบทบาทมีสิทธิ์การเข้าถึงฟังก์ชันที่แตกต่างกัน

2.1 ตารางบทบาทและสิทธิ์

ลำดับชื่อบทบาทคำอธิบายสิทธิ์การเข้าถึง

2 SuperAdmin ผู้ดูแลระดับโรงพยาบาล เข้าถึงเมนู Admin ได้ทั้งหมด แต่จำกัดขอบเขตเฉพาะโรงพยาบาลที่สังกัด

การเข้าสู่ระบบ (Login)

3.1 ขั้นตอนการเข้าสู่ระบบ

เปิดเว็บเบราว์เซอร์และเข้าไปยัง URL ของระบบ ระบบจะแสดงหน้าเข้าสู่ระบบพร้อมข้อความ "Welcome — Sign in to X-RayCare QC System"

  1. กรอก Username — ชื่อผู้ใช้ที่ได้รับจากผู้ดูแลระบบ
  2. กรอก Password — รหัสผ่านของบัญชีผู้ใช้ (สามารถคลิกไอคอนรูปตาทางด้านขวาเพื่อแสดง/ซ่อนรหัสผ่าน)
  3. เลือก โรงพยาบาล — เลือกโรงพยาบาลที่ท่านสังกัดจากรายการแบบเลื่อนลง (Drop-down)
  4. คลิกปุ่ม "Sign In" เพื่อเข้าสู่ระบบ
  5. ระบบจะนำท่านเข้าสู่หน้า Dashboard ตามบทบาทของท่านโดยอัตโนมัติ
ช่องข้อมูลคำอธิบายตัวอย่าง
Usernameชื่อผู้ใช้ที่ได้รับจากผู้ดูแลระบบSuperadmin
Passwordรหัสผ่านของบัญชีผู้ใช้Superadmin1234
โรงพยาบาลเลือกโรงพยาบาลที่สังกัดจากรายการโรงพยาบาลตัวอย่าง

การนำทางหลังเข้าสู่ระบบ: ระบบจะพาท่านไปยังหน้าแรกตามบทบาทโดยอัตโนมัติ ดังนี้

  • Admin / SuperAdmin / Root Admin → หน้า Admin Dashboard
  • Radiological Technologist → หน้า Dashboard
  • Engineer → หน้า Engineer Dashboard

3.2 กรณีเข้าสู่ระบบไม่สำเร็จ

หากกรอกข้อมูลไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือนสีแดงใต้แบบฟอร์ม ท่านสามารถตรวจสอบสาเหตุได้ตามรายการต่อไปนี้:

ข้อความแจ้งเตือนสาเหตุที่เป็นไปได้
กรุณากรอก Username และ Passwordยังไม่ได้กรอกชื่อผู้ใช้หรือรหัสผ่าน
ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้องชื่อผู้ใช้หรือรหัสผ่านไม่ตรงกับข้อมูลในระบบ
เกิดข้อผิดพลาด กรุณาลองใหม่อีกครั้งเซิร์ฟเวอร์ไม่สามารถตอบสนองได้ หรือเกิดปัญหาการเชื่อมต่อ
✓ เคล็ดลับ
ตรวจสอบให้แน่ใจว่าท่านเลือกโรงพยาบาลที่ถูกต้อง เนื่องจากระบบจะตรวจสอบทั้งชื่อผู้ใช้ รหัสผ่าน และโรงพยาบาลพร้อมกัน หากเลือกโรงพยาบาลผิด จะไม่สามารถเข้าสู่ระบบได้แม้ชื่อผู้ใช้และรหัสผ่านจะถูกต้อง

5.1.3 ตารางรายการเครื่อง

แสดงรายการเครื่องเอกซเรย์ทั้งหมดที่ลงทะเบียน พร้อมข้อมูล: ชื่อเครื่อง (ยี่ห้อ/รุ่น), ห้องตรวจ, ผู้ดูแลเครื่อง และสถานะ

คลิกปุ่ม "Check" ในคอลัมน์ Action เพื่อเริ่มทำ Daily Check ของเครื่องนั้น ระบบจะนำท่านไปยังหน้า Checklist โดยอัตโนมัติ

5.1.4 ปฏิทินกิจกรรม

แสดงปฏิทินเดือนปัจจุบัน โดยวันที่มีกำหนดการจะแสดงป้ายกำกับ Monthly หรือ Daily สามารถคลิกที่วันที่เพื่อดูรายละเอียดกิจกรรม

5.1.5 สถานะเครื่อง (Equipment Readiness)

แสดงสถานะความพร้อมของเครื่องเอกซเรย์แต่ละเครื่อง:

  • พร้อมใช้งาน — ผ่านการตรวจ QC ล่าสุด
  • ไม่พร้อมใช้งาน — ไม่ผ่านการตรวจ QC หรือยังไม่มีข้อมูลการตรวจสอบ

5.3 Daily Check — การตรวจสอบประจำวัน

5.3.1 ข้อมูลที่แสดงด้านบน

  • ชื่อเครื่อง — เครื่องที่เลือกตรวจสอบ
  • รุ่น — รุ่นของเครื่อง
  • ห้อง — ห้องที่ตั้งเครื่อง
  • วันที่ — วันที่ปัจจุบัน (กำหนดโดยอัตโนมัติ)
  • ผู้ทดสอบ — ชื่อผู้ใช้ที่เข้าสู่ระบบ
  • เวลา — เวลาปัจจุบัน (อัปเดตโดยอัตโนมัติ)

5.3.2 รายการที่ต้องทำวันนี้ (ตาม Schedule)

หากมีรายการตรวจสอบที่ครบกำหนดตาม PM Schedule ระบบจะแสดงแถบรายการที่ต้องดำเนินการ เช่น:

F1/F2 (กำลังทำ)
F3–F6
F7–F8

5.3.3 ตารางบันทึกผลการตรวจ

ตารางแบบบันทึก "การดูแลรักษาและตรวจสอบเครื่องเอกซเรย์" ประกอบด้วยคอลัมน์:

5.3.4 การแนบไฟล์ภาพ

  1. คลิกปุ่ม "เลือกไฟล์" ใต้ช่องหมายเหตุของแต่ละรายการ
  2. เลือกไฟล์รูปภาพจากเครื่องคอมพิวเตอร์ (รองรับรูปแบบ JPG, PNG, GIF, WebP)
  3. ภาพจะแสดงตัวอย่าง (Preview) ด้านล่างทันที
  4. หากต้องการลบภาพ คลิกปุ่ม ✕ ข้างชื่อไฟล์

5.3.5 ปุ่มดำเนินการ

  • "ผ่านทั้งหมด" — เลือก "ผ่าน" ให้กับทุกรายการพร้อมกัน
  • "ถัดไป" / "บันทึกและดำเนินการต่อ" — บันทึกผลและนำไปยังหน้าถัดไป (Checklist Next หรือ Monthly Check ตาม Schedule)
  • "บันทึก" — บันทึกผลโดยไม่ไปยังหน้าถัดไป

5.5 PM Schedule — ตารางบำรุงรักษาเชิงป้องกัน

เส้นทาง: /pm-schedule   สิทธิ์: Admin, Radiological Technologist

หน้า PM Schedule แสดงปฏิทินสำหรับจัดการตารางบำรุงรักษาเชิงป้องกัน (Preventive Maintenance)

5.5.1 องค์ประกอบหน้าจอ

  • การ์ดวันที่ — แสดงวันที่และวันในสัปดาห์ปัจจุบัน
  • ปฏิทิน — แสดงปฏิทินเดือนปัจจุบัน เลื่อนเดือนด้วยปุ่ม < และ >
  • เครื่องหมาย ★ — วันที่มีกำหนดการตรวจสอบจะแสดงดาวสีเหลืองเป็นสัญลักษณ์

5.5.2 การตั้งค่ารอบ PM

  1. คลิกที่วันที่ต้องการในปฏิทิน — ระบบจะแสดง Popup
  2. คลิกไอคอน ตั้งค่ารอบ (รูปเฟือง) เพื่อเปิดหน้าต่างตั้งค่า
  3. กำหนดรายละเอียดตารางบำรุงรักษา ดังนี้:
    ช่องข้อมูลคำอธิบาย
    วันเริ่มต้นวันที่เริ่มต้นรอบการตรวจสอบ PM
    ความถี่เลือกรอบการตรวจ: 1 เดือน / 3 เดือน / 6 เดือน
    คำอธิบายรายละเอียดของงานบำรุงรักษา
    ประเภทแบบบันทึกเลือกแบบบันทึกที่ต้องดำเนินการ (F1/F2, F3–F6, F7–F8 ฯลฯ)
  4. คลิก "Save" เพื่อบันทึกตารางบำรุงรักษา

5.5.3 ระบบแจ้งเตือนอัตโนมัติ

เมื่อมีกำหนด PM ใกล้ถึง ระบบจะคำนวณวันที่ตรวจสอบถัดไปจาก วันเริ่มต้น + ความถี่ และแสดงการแจ้งเตือนบน Dashboard โดยอัตโนมัติ ตามระดับความเร่งด่วนที่ระบุไว้ในหัวข้อ 5.1.1

5.7 Analytical — ศูนย์วิเคราะห์ความเสี่ยง

เส้นทาง: /analytics   สิทธิ์: Admin, Radiological Technologist

หน้าศูนย์วิเคราะห์ความเสี่ยง (Risk Prevention Analytics) แสดงผลวิเคราะห์ข้อมูลที่ครอบคลุมสำหรับแผนกเอกซเรย์

5.7.1 ตัวกรองข้อมูล

ด้านขวาบนของหน้ามีเมนูเลือก "ปี พ.ศ." สำหรับกรองข้อมูลแสดงผลตามปีที่ต้องการ

5.7.2 การ์ด KPI (Key Performance Indicators)

KPIคำอธิบายเกณฑ์สี
เครื่องเอกซเรย์ทั้งหมดจำนวนเครื่องที่ลงทะเบียนในระบบน้ำเงิน (ข้อมูล)
อัตราผ่าน QC ทั้งปีร้อยละ Checklist ที่ผ่านเกณฑ์≥80% 60–79% <60%
แจ้งซ่อมรอดำเนินการจำนวนคำขอแจ้งซ่อมที่ยังไม่ดำเนินการ0 1–3 >3
ระดับความเสี่ยงรวมการประเมินความเสี่ยงโดยรวมเขียว / เหลือง / แดง (ตามการคำนวณ)

5.7.3 กราฟและแผนภูมิ

  • กราฟเส้น (Line Chart) — แนวโน้มการแจ้งซ่อมและผล QC รายเดือน
  • แผนภูมิวงกลม (Donut Chart) — สัดส่วนการแจ้งซ่อมจำแนกตามเครื่อง
  • แผนภูมิแท่ง (Bar Chart) — สถานะการตรวจ QC จำแนกตามประเภทแบบฟอร์ม

5.7.4 การประเมินความเสี่ยงรายเครื่อง

แสดงการ์ดรายเครื่องพร้อมข้อมูล: คะแนนสุขภาพ (Health Score), จำนวนการแจ้งซ่อม, QC ไม่ผ่าน, เกินกำหนด และข้อความระดับความเสี่ยง เช่น:

  • วิกฤต — ต้องดำเนินการแก้ไขทันที
  • เฝ้าระวัง — ต้องติดตามอย่างใกล้ชิด
  • ติดตาม — สถานะปกติแต่ต้องติดตามต่อเนื่อง

คำถามที่พบบ่อย (FAQ)

Q1: ลืมรหัสผ่านต้องทำอย่างไร?

A: ติดต่อผู้ดูแลระบบ (Admin) ของโรงพยาบาลเพื่อให้ตั้งรหัสผ่านใหม่ผ่านหน้า User Accounts ระบบไม่มีฟังก์ชันรีเซ็ตรหัสผ่านด้วยตนเอง

Q2: ไม่สามารถเข้าสู่ระบบได้ แม้กรอกข้อมูลถูกต้อง

A: ตรวจสอบว่าท่านเลือกโรงพยาบาลที่ถูกต้องตรงกับบัญชีผู้ใช้ เนื่องจากระบบตรวจสอบทั้งชื่อผู้ใช้ รหัสผ่าน และโรงพยาบาลพร้อมกัน

Q3: เครื่องเอกซเรย์ที่ลงทะเบียนแล้วไม่แสดงบน Dashboard

A: เครื่องที่ลงทะเบียนผ่านหน้า Equipment จะแสดงบน Dashboard โดยอัตโนมัติ หากไม่แสดง ให้รีเฟรชหน้าเว็บโดยกดคีย์ F5 หรือ Ctrl + R

Q4: การแจ้งเตือน PM Schedule ทำงานอย่างไร?

A: ระบบคำนวณวันที่ตรวจสอบถัดไปจาก วันเริ่มต้น + ความถี่ เมื่อวันที่ถัดไปใกล้ถึงจะแสดงการแจ้งเตือนบน Dashboard ตามระดับดังนี้:

  • มากกว่า 7 วัน → เขียว (ข้อมูล)
  • 4–7 วัน → เหลือง (เตือนล่วงหน้า)
  • 1–3 วัน → แดง (เร่งด่วน)
  • วันนี้ → แดง + Pulse (TODAY)

Q5: วิธีพิมพ์รายงานเป็น PDF

A: ไปที่เมนู Export PDF → กรองข้อมูลตามเงื่อนไข → คลิก "ตัวอย่างไฟล์" → ระบบเปิดหน้า Print View → กดคีย์ Ctrl + P → เลือก "Save as PDF" จากเมนูเครื่องพิมพ์

Q6: Root Admin ต่างจาก Admin อย่างไร?

A:

  • Root Admin — เข้าถึงได้ทุกโรงพยาบาล สามารถเพิ่ม/ลบโรงพยาบาล สร้างบัญชี Root Admin อื่นได้ และสลับโรงพยาบาลจาก Top Bar
  • Admin — เข้าถึงได้เฉพาะโรงพยาบาลที่สังกัดเท่านั้น

Q7: วิศวกรสามารถเข้าถึงแบบบันทึก QC ได้หรือไม่?

A: ไม่สามารถเข้าถึงได้โดยตรง วิศวกรมีสิทธิ์เข้าถึงเฉพาะ Engineer Dashboard, Engineer Analytics และ Engineer Request เท่านั้น หากต้องการดูข้อมูล QC ให้ติดต่อ Admin หรือนักรังสีเทคนิค

Q8: สามารถใช้งานบนมือถือได้หรือไม่?

A: ได้ ระบบรองรับการแสดงผลแบบ Responsive Design สามารถใช้งานผ่านเบราว์เซอร์บนมือถือและแท็บเล็ต แถบเมนูด้านข้างจะเปลี่ยนเป็นโหมด Overlay สามารถเปิด/ปิดได้ด้วยปุ่ม ☰ ที่แถบด้านบน

Q9: ภาพที่แนบในระบบจัดเก็บอย่างไร?

A: ภาพจะถูกแปลงเป็นรูปแบบ Base64 String และจัดเก็บในฐานข้อมูล PostgreSQL โดยตรง ไม่มีการอัปโหลดเป็นไฟล์แยกต่างหาก

Q10: สามารถลบโรงพยาบาลได้เมื่อไร?

A: สามารถลบได้เฉพาะเมื่อโรงพยาบาลนั้นไม่มีผู้ใช้งานและไม่มีเครื่องเอกซเรย์ลงทะเบียนอยู่ จำเป็นต้องย้ายหรือลบข้อมูลเหล่านั้นให้หมดก่อนจึงจะดำเนินการลบโรงพยาบาลได้
